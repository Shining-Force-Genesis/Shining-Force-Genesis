# Shining Force Genesis

This is a currently work in progress (WIP) remake of the original Shining Force 1 and 2.

## Install

Just download the latest release from the [release section](https://github.com/Shining-Force-Genesis/Shining-Force-Genesis/releases) extract the exe from the zip file and run it.

## Controls

A - A action
S - B action (cancel)
D - C action (talk or search if someone in front of you)

Arrow keys - to move

F11 - Toggle Fullscreen 

Page Down - Sets the game to 3x speed to get through stuff faster

Backspace - Moves you to battle 3 immedately (mainly for quick developer testing)
